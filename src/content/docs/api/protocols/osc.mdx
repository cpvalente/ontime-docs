Control Ontime with OSC messages from show control software, lighting and sound consoles. \
Turn OSC input on in `Editor` -> `Settings` -> `Automation`. By default, Ontime listens on UDP port `8888`.

```bash
/ontime/<action> <argument>
# eg. /ontime/start/next
```

- Some actions take an argument, such as a cue or a duration. Others take none.
- OSC is one way. To get feedback, send data back from Ontime with [automation outputs](/api/automation/).
- Check what Ontime receives in `Editor` -> `Settings` -> `Network` -> `Event log`.
- OSC is not available on Ontime Cloud.

## Playback

| Action | Address and argument |
| :--- | :--- |
| Start the loaded event | `/ontime/start` |
| Start the next event | `/ontime/start/next` |
| Start the previous event | `/ontime/start/previous` |
| Start an event by position (from 1) | `/ontime/start/index <position>` |
| Start an event by ID | `/ontime/start/id <event-id>` |
| Start an event by cue | `/ontime/start/cue <cue>` |
| Load the next event | `/ontime/load/next` |
| Load the previous event | `/ontime/load/previous` |
| Load an event by position (from 1) | `/ontime/load/index <position>` |
| Load an event by ID | `/ontime/load/id <event-id>` |
| Load an event by cue | `/ontime/load/cue <cue>` |
| Pause | `/ontime/pause` |
| Stop | `/ontime/stop` |
| Reload the current event | `/ontime/reload` |
| Start [Roll mode](/quick-tips/roll/) | `/ontime/roll` |
| Add time to the running event | `/ontime/addtime/add <milliseconds>` |
| Remove time from the running event | `/ontime/addtime/remove <milliseconds>` |

You can add or remove up to one hour at a time.

## Change an event

Put the field in the address and the new value in the argument. See the [fields you can change](/api/data/event-data/#fields-you-can-change-over-the-api).

```bash
/ontime/change/<event-id>/title <new-title>
/ontime/change/<event-id>/custom:<field-name> <new-value>
```

## Messages

Control the messages on the [stage timer](/interface/automated/stage-timer/) view.

| Action | Address and argument |
| :--- | :--- |
| Set the [secondary message](/features/secondary-message/) | `/ontime/message/secondary <text>` |
| Set the timer message | `/ontime/message/timer/text <text>` |
| Show or hide the timer message | `/ontime/message/timer/visible true` or `false` |
| Make the timer message blink | `/ontime/message/timer/blink true` or `false` |
| Black out all stage timer screens | `/ontime/message/timer/blackout true` or `false` |
| Choose what shows in the secondary field | `/ontime/message/timer/secondarySource <source>` |

`<source>` is `secondary` for the secondary message, or `aux1`, `aux2` or `aux3` for an auxiliary timer. Any other value, such as `off`, hides the secondary field.

## Auxiliary timers

Ontime has three [auxiliary timers](/features/aux-timer/), numbered `1` to `3`. They run separately from the rundown.

| Action | Address and argument |
| :--- | :--- |
| Start | `/ontime/auxtimer/1/start` |
| Pause | `/ontime/auxtimer/1/pause` |
| Stop | `/ontime/auxtimer/1/stop` |
| Set the duration | `/ontime/auxtimer/1/duration <milliseconds>` |
| Count up or down | `/ontime/auxtimer/1/direction count-up` or `count-down` |
| Add time (negative to remove) | `/ontime/auxtimer/1/addtime <milliseconds>` |
