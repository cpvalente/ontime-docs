Run Ontime without a desktop app, on a server, a venue machine or a Raspberry Pi. \
Once it runs, open `http://<ip-address>:4001/editor` from any device on the network.

## Run Ontime with Docker

<Steps>

1. [Install Docker](https://docs.docker.com/engine/install/).

2. Save this as `compose.yaml`, and set `TZ` to your [timezone](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones):

   ```yaml
   services:
     ontime:
       container_name: ontime
       image: getontime/ontime:latest
       ports:
         - "4001:4001/tcp"   # the web app and APIs
         - "8888:8888/udp"   # OSC input
         - "9999:9999/udp"   # OSC output
       volumes:
         - "./ontime-data:/data/"
       environment:
         - TZ=Europe/Oslo
       restart: unless-stopped
   ```

3. Start it:

   ```bash
   docker compose up -d
   ```

</Steps>

The image is [getontime/ontime on Docker Hub](https://hub.docker.com/r/getontime/ontime).

### Ports

- `4001` serves the app. To use plain `http://<ip-address>/editor` without a port, map it to port 80: `"80:4001/tcp"`.
- `8888` and `9999` are the default OSC input and output ports. Remove them if you don't use OSC.

### Data

The example stores everything in `./ontime-data`. To keep the parts separate, map them one by one:

```yaml
    volumes:
      - "./ontime-projects:/data/projects/"   # project files
      - "./ontime-styles:/data/styles/"       # custom CSS
      - "./ontime-external:/data/external/"   # files you serve through Ontime
```

### Timezone

Containers run in UTC unless you set `TZ`. Ontime's clock and schedule follow this timezone.

## Run Ontime with NPM

You need the [Node.js version listed by Ontime](https://github.com/cpvalente/ontime/blob/master/package.json).

```bash
# install, then run
npm install -g @getontime/cli
ontime

# or run once without installing
npx @getontime/cli
```

## Troubleshooting

### I can see the app but no timers start

Ontime sends timer data over WebSockets. Behind a reverse proxy, you need to allow WebSocket connections. \
See the guides for [NGINX](https://nginx.org/en/docs/http/websocket.html) and [Synology](https://mariushosting.com/synology-some-docker-containers-need-websocket/).

### The clock shows the wrong time

Set `TZ` in `compose.yaml` to your timezone, then restart the container.
