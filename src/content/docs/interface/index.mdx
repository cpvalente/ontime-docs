Every view is a page in the browser. Give each person the view for their role.

## Which view for which person

| View | For | Path |
| --- | --- | --- |
| [Editor](/interface/production/app-editor/) | The show runner, to build and run the rundown | `/editor` |
| [Cuesheet](/interface/production/cuesheet/) | Departments, to follow and add their data | `/cuesheet` |
| [Operator](/interface/production/operator/) | Operators and stage managers | `/op` |
| [Stage timer](/interface/automated/stage-timer/) | Presenters and talent | `/timer` |
| [Countdown](/interface/automated/countdown/) | Anyone waiting for a specific event, like a break | `/countdown` |
| [Backstage](/interface/automated/backstage/) | Crew backstage | `/backstage` |
| [Timeline](/interface/automated/timeline/) | Producers and signage | `/timeline` |
| [Studio clock](/interface/automated/studio-clock/) | Broadcast studios | `/studio` |
| [Project info](/interface/automated/project/) | Crew who need contacts and project details | `/info` |

The Editor, Cuesheet and Operator are interactive. The others are displays for screens nobody touches during the show.

## Open a view

Add the path to the address of Ontime:

```
Local:  http://<ip-address>:<port>/timer     eg. http://192.168.10.1:4001/timer
Cloud:  https://cloud.getontime.no/<stage>/timer
```

See [network and security](/additional-notes/network-and-security/) to make Ontime reachable on your network.

Views save their settings in the URL, so you can bookmark or share a configured view. See [configuring views](/quick-tips/configuring-views/), and [URL presets](/features/url-presets/) for short links.
