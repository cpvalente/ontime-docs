## Installing Ontime

Ontime is available as a desktop app for Windows, macOS and Linux, including Raspberry Pi. You can also [self-host it with Docker](/quick-tips/headless-ontime/).

Download the latest release from the [Ontime download page](https://www.getontime.no/download) and run the installer for your platform. \
If your operating system warns you about an unsigned app, see our [notes on unsigned apps](/additional-notes/unsigned-app/).

## Build your first rundown

<Steps>

1. Open Ontime. The app opens the **Editor**, or go to `http://localhost:4001/editor` in a browser.

2. In the rundown, choose **Add Event**. Give it a title and a duration. Add a few more.

3. Press **Start**, or the Space bar, to run the first event. Press **Next** to move on.

</Steps>

Learn more in [how a rundown works](/concepts/rundown/).

## Choose where to run Ontime

| | Best for | How to start |
| --- | --- | --- |
| **Desktop app** | Rehearsals, touring shows and show-site operation on a local network | [Download Ontime](https://www.getontime.no/download) |
| **Docker or self-hosted** | Venues, servers and media machines managed by your team | [Self-host with Docker](/quick-tips/headless-ontime/) |
| **Ontime Cloud** | Remote preparation and hosted access, without managing infrastructure | [Ontime Cloud](/ontime-cloud/) |

All three use the same project format, so you can [move a project](/quick-tips/import-export/) between them at any time.
