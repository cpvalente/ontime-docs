## Is Ontime open source and self-hostable?
Yes. Ontime is fully open source and self-hostable. Self-hosted and Cloud deployments run the same Ontime app and use the same project format.

[Ontime Cloud](/ontime-cloud/) adds hosting features of its own, which are not part of the self-hosted app: read-only shares, project archives and a multi-stage overview. See [why use Ontime Cloud](/ontime-cloud/#why-use-ontime-cloud).

You can move project data between Cloud, local, and self-hosted deployments, so your data stays yours.

## Can I run Ontime on an Intel Mac?
Yes. Ontime has separate builds for Apple Silicon and Intel (x64) Macs. Make sure you download the right one. \
Download links can be found in [the download page](https://www.getontime.no/download), or get the [Apple Silicon](https://www.getontime.no/download/macos-arm64) or [Intel](https://www.getontime.no/download/macos-x64) build directly.

## Which Linux or Raspberry Pi build do I need?
Ontime distributes two Linux packages depending on your architecture.
- Are you on a **normal PC / desktop**, download the [64-bit AppImage](https://www.getontime.no/download/linux-x64)
- Are you on a **Raspberry Pi 4 or newer**, download the [Arm 64-bit AppImage](https://www.getontime.no/download/linux-arm64)
